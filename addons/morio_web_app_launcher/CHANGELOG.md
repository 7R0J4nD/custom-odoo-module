# Changelog

## 19.0.1.0.0

- Add a responsive tile grid to the desktop application launcher.
- Reuse the current user's Odoo menu data and native app-selection behavior.

## 19.0.1.1.0

- Show the tile grid as Odoo's full-screen default landing screen.
- Keep the app selection grid in the navbar and mobile sidebar.

## 19.0.1.2.0

- Preserve the standard navbar and systray on the landing screen.
- Size the landing content below the navbar.

## 19.0.1.3.0

- Show the active company's logo in place of the Discuss systray icon.
- Keep the message dropdown and unread counter available.

## 19.0.1.4.0

- Add a launcher settings route with a persistent shared background color picker.
- Hide the home-menu button on the launcher page and make it return to the launcher from other apps.
- Use a distinct navbar color on launcher pages.
